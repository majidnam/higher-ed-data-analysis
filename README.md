# higher-ed-data-analysis

This data analysis project explores outcomes data for graduates who obtained qualifications from UK education providers.


The source code and analysis in this project is licensed under BSD 3-Clause; see the LICENSE.md file included in this project for license information. 

This project also uses data from HESA  under CC BY 4.0; see the 'Data Attribution and Licensing' section below for data attribution and license information. 


## Data Attribution and Licensing
This project uses data from the Higher Education Statistics Agency, HESA (www.hesa.ac.uk), under a [Creative Commons Attribution 4.0 International License (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). The license's deed is at https://creativecommons.org/licenses/by/4.0/ and legal code at https://creativecommons.org/licenses/by/4.0/legalcode.

The title of the data set used in this project is:
 *  `'UK permanent address graduates in full-time paid employment in the UK by subject area of degree, salary band, country of provider, provider type, level of qualification obtained, mode of former study, skill group, work population marker and academic year'`

The data was obtained from the HESA website via the following webpage:
https://www.hesa.ac.uk/data-and-analysis/graduates/table-30,
by clicking the 'Download source data (zip)' link on the page. This link's URL is: 
https://www.hesa.ac.uk/data-and-analysis/graduates/table-30.zip.

I have made modifications and applied transformations to this data throughout this project, as shown and/ or described within the .ipynb file.
