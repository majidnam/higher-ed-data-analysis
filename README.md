# higher-ed-data-analysis

This data analysis project explores outcomes data for graduates who obtained qualifications from UK education providers.

This project uses data from HESA, which is licensed under a CC-BY-4.0 license; see the 'Data Attribution and Licensing' section below for data attribution and license information.

## Data Attribution and Licensing
This project uses data published by the Higher Education Statistics Agency, HESA (www.hesa.ac.uk). This data is licensed under a Creative Commons Attribution 4.0 International Public License  (CC-BY-4.0). See full license text on: https://creativecommons.org/licenses/by/4.0/legalcode.

The title of the dataset used in this project is:
 *  `'UK permanent address graduates in full-time paid employment in the UK by subject area of degree, salary band, country of provider, provider type, level of qualification obtained, mode of former study, skill group, work population marker and academic year'`

The data was obtained from the HESA website via the following page:
https://www.hesa.ac.uk/data-and-analysis/graduates/table-30,
through clicking the 'download source data' link on the page. The link's URL is: 
https://www.hesa.ac.uk/data-and-analysis/graduates/table-30.zip.

I have made modifications and applied transformations to the data throughout this project. These are shown or described within the .ipynb file.
