# higher-ed-data-analysis

This data analysis project looks at outcomes data for graduates who obtained qualifications from UK education providers.

The data used in this project is authored by HESA, and is licensed under the CC-BY-4.0 license; see the 'Data Attribution and Licensing' section below for attribution and license information.

The title of the dataset used in this project is:
 *  `'UK permanent address graduates in full-time paid employment in the UK by subject area of degree, salary band, country of provider, provider type, level of qualification obtained, mode of former study, skill group, work population marker and academic year'`

The dataset was obtained from the HESA website via the following page:
https://www.hesa.ac.uk/data-and-analysis/graduates/table-30,
through the 'download source data' link on the page.

The transformations I have applied to the dataset are shown within the  ipynb file.
